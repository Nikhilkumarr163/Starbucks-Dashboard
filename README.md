1,** ☕ Starbucks Business Insights Dashboard (Power BI)**

2, **Overview**
An interactive Power BI dashboard analyzing Starbucks' global beverage menu — 
covering nutrition, caffeine content, and store distribution — to uncover 
patterns in calories, sugar, caffeine, and beverage category performance. 
Built to simulate a real-world business intelligence use case for a 
food & beverage company.

3, **Purpose**
To transform raw nutritional and store-location data into clear, actionable 
insights that support product strategy, health-conscious menu decisions, 
and market presence analysis.

4, **🛠️ Tech Stack**
- **Power BI Desktop** — data visualization & dashboard design
- **Power Query** — data cleaning & transformation (ETL)
- **DAX (Data Analysis Expressions)** — calculated measures & KPIs
- **Python (via Power BI Py visual)** — advanced analytics/scripting
- **Excel / CSV** — raw data source files

5, **🗂️ Data Source**
- Starbucks nutrition dataset (Calories, Sugar, Protein, Caffeine, 
  Sodium, Fat, Vitamins, Cholesterol, Iron, etc.)
- Starbucks global store directory (Brand, City, Country, Coordinates, 
  Store Number, Timezone)

 6,**✨ Key Features**
- 📊 **KPI Cards** — Total Beverages, Avg. Sugar, Avg. Calories, Avg. Caffeine
- 🎚️ **Interactive Filters** — Protein Range slider & Beverage Prep dropdown
- 📈 **Category Trend Analysis** — Average calories across beverage categories
- 🌍 **Store Distribution Chart** — Beverage count by category (bar chart)
- 🍩 **Donut Chart** — Calorie distribution by beverage category
- ☕ **Caffeine Insights** — Average caffeine by category + Top 5 highest 
  caffeine beverages (with images)
- 🎨 **Custom Branded UI** — Starbucks-themed color palette and layout 
  for a polished, presentation-ready dashboard
