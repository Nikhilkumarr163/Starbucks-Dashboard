# ☕ Starbucks Business Insights Dashboard (Power BI)

## 📌 Overview
An interactive Power BI dashboard analyzing Starbucks' global beverage menu — covering nutrition, caffeine content, and store distribution — to uncover patterns in calories, sugar, caffeine, and beverage category performance. Built to simulate a real-world business intelligence use case for a food & beverage company.

## 🎯 Purpose
To transform raw nutritional and store-location data into clear, actionable insights that support product strategy, health-conscious menu decisions, and market presence analysis.

## 🛠️ Tech Stack
- **Power BI Desktop** — data visualization & dashboard design
- **Power Query** — data cleaning & transformation (ETL)
- **DAX (Data Analysis Expressions)** — calculated measures & KPIs
- **Python (via Power BI Py visual)** — advanced analytics/scripting
- **Excel / CSV** — raw data source files

## 🗂️ Data Source
- Starbucks nutrition dataset (Calories, Sugar, Protein, Caffeine, Sodium, Fat, Vitamins, Cholesterol, Iron, etc.)
- Starbucks global store directory (Brand, City, Country, Coordinates, Store Number, Timezone)

## ✨ Key Features
- 📊 **KPI Cards** — Total Beverages, Avg. Sugar, Avg. Calories, Avg. Caffeine
- 🎚️ **Interactive Filters** — Protein Range slider & Beverage Prep dropdown
- 📈 **Category Trend Analysis** — Average calories across beverage categories
- 🌍 **Store Distribution Chart** — Beverage count by category
- 🍩 **Donut Chart** — Calorie distribution by beverage category
- ☕ **Caffeine Insights** — Average caffeine by category + Top 5 highest caffeine beverages
- 🎨 **Custom Branded UI** — Starbucks-themed color palette and polished layout

## 🚀 How to Use
1. Clone or download this repository
2. Open `Starbucks_analysis.pbix` in Power BI Desktop
3. Refresh data source if reconnecting to live data
4. Explore insights using slicers and interactive visuals
